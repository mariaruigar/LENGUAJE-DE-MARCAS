Etiquetas HTML

Texto

En HTML tenemos varias etiquetas que sirven para escribir texto

Encabezados

Las etiquetas de encabezado se escriben como hx, donde x va de 1 a 6

Párrafos

La etiquetas para escribir párrafos es "p"

Énfasis

Damos énfasis a una parte de un texto usando la etiqueta "strong", que pone el texto en negrita, o la etiqueta "em", que lo pone en cursiva o itálica.

Listas

Listas desordenadas

Si quiero crear una lista desordenada (unordered list), utilizaré la etiqueta "ul". Cada uno de los elementos de esa lista será un "li" (list item).

Listas ordenadas

Si quiero crear una lista ordenada (ordered list), utilizaré la etiqueta "ol". Nuevamente, cada uno de esos elementos dsentor de la lista sera "li"

Enlaces

Si quiero crear un enlace a otra página usaré la etiqueta "a". Por ejemplo:

Éste es un enlace a Google
Esta es mi lista de la compra

Imágenes

Cuando quiero inserta una imagen uso una etiqueta "a"

Esta etiqueta tiene el atributo obligatorio "src" para indicar la ruta de imagen y también es importante usar el atributo "alt" para dar un texto alternativo en caso de que la ruta esté rota o el usuario no pueda ver las imágenes
